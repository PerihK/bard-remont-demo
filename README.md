# БАРД — ремонт с характером

Демонстрационная концепция нового сайта [БАРД-Ремонт](https://toremont.ru/), Санкт-Петербург. React, Vite, адаптивная вёрстка, локальные шрифты Manrope.

## Запуск

```sh
npm install
npm run dev
```

Для production: `npm run build`. Готовая статика находится в `dist/`.

## Что работает

- Обложка с переключением между концепцией и реальными интерьерами.
- Четыре объекта с фильтром «Квартиры / Бизнес», галереями и управлением стрелками клавиатуры.
- Калькулятор: 20–200 м², новостройка / вторичное жильё, три уровня ремонта, черновые материалы, бюджет и сроки.
- Сохранение расчёта в текстовый файл.
- Интерактивные этапы ремонта и FAQ.
- Форма собирает локальный бриф, который можно скачать. Серверной отправки нет.
- Навигация, мобильная компоновка, доступные диалоги и режим reduced motion.

## Данные и изображения

Галереи содержат реальные фотографии из опубликованного портфолио компании. Исходные водяные знаки сохранены. Источники: [docs/assets.json](docs/assets.json).

Первый экран — отдельная AI-визуализация, не выполненный объект компании. Она подписана в интерфейсе. Инструмент и полный промпт: [docs/hero-prompt.md](docs/hero-prompt.md).

Цифры 5200+, 80+ и гарантия 2 года, контакты и сведения о процессе взяты с сайта компании. Площади, цены и сроки реальных объектов не выдумывались. Названия историй — редакционные.

Ставки калькулятора иллюстративные: 6500 / 12500 / 18500 ₽ за м² работ; коэффициент вторичного жилья 1,18; черновые материалы 2000 / 4500 ₽ за м². Диапазон ±10% служит демонстрацией интерфейса, не является подтверждённой точностью оценки или коммерческим предложением. Модель сроков также иллюстративная. Чистовые материалы, мебель, техника и согласования не включены.

Сайт помечен `noindex, nofollow`. Формы не выполняют сетевых запросов и не хранят данные на сервере. Аналитика и внешние виджеты отсутствуют.
